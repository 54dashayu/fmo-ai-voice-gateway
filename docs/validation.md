# 验证分级

## A. 只读检查

- 服务状态、监听端口、资源使用量。
- AI客户端是否连接到预期Broker和Topic。
- SAS/CA与现有FMO用户是否正常。
- 不采集其他用户原始语音，不发布MQTT消息。

## B. 模拟验证

- `--validate-only` 检查环境和门禁。
- TTS测试音频 -> ASR -> 文本模型 -> TTS离线闭环。
- 生成结果只写权限受限临时目录并自动过期。
- 不连接PTT，不在频道播放。
- 在临时目录验证自动回复／鹦鹉原声回放／关闭三态互斥，以及关闭鹦鹉恢复开启前状态。
- 使用合成图片验证 Robot36、`-24 dB` 正文电平、60秒准备、独占和停止安全门；默认不发布MQTT。
- 验证NAS图库、音乐和公共SSTV目录未配置时能够安全降级，不访问任何作者环境。

## 安装与升级矩阵

| 场景 | 必须验证 |
|---|---|
| 全新安装 | 专用用户、`0600` 配置、所有真实能力默认关闭、后台仅回环可达 |
| `v0.1.x -> v0.2.x` | env/config/state保留、新代码实际启动、失败自动回退 |
| `v0.2.x -> 前一版本` | `current` 原子切换、两个服务恢复、用户话术/计划/开关不删除 |
| x86_64 / ARM64 | Python 3.10–3.12、libopus、ffmpeg、systemd服务和doctor |

没有实测的平台必须在 Release 说明中标为“声明支持、尚未实机验证”，不能用同架构单元测试替代发行版安装验收。

## C. 真实语音验证

- 仅服务器所有者批准的呼号和短语音。
- 先确认频道空闲与接收端监听者就位。
- 明确AI身份，不使用与在线真实用户相同的发言标识。
- 以接收端实际听到完整语音作为成功证据，不能只看MQTT发布计数。
