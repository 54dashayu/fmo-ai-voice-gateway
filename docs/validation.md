# 验证分级

## A. 只读检查

- 服务状态、监听端口、资源使用量。
- AI客户端是否连接到预期Broker和Topic。
- SAS/CA与现有FMO用户是否正常。
- 不采集其他用户原始语音，不发布MQTT消息。

## B. 模拟验证

- `--validate-only` 检查环境和门禁。
- TTS测试音频 -> ASR -> 文本模型 -> TTS离线闭环。
- 生成结果只写权限受限临时目录并自动过期。
- 不连接PTT，不在频道播放。

## C. 真实语音验证

- 仅服务器所有者批准的呼号和短语音。
- 先确认频道空闲与接收端监听者就位。
- 明确AI身份，不使用与在线真实用户相同的发言标识。
- 以接收端实际听到完整语音作为成功证据，不能只看MQTT发布计数。
