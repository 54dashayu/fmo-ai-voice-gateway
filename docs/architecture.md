# 架构与安全边界

## 推荐同机部署

```text
公网FMO客户端 -> EMQX公网监听 -> SAS/CA鉴权
                                  |
                                  +-> 127.0.0.1:1884 AI专用监听
                                      -> AI Gateway
                                      -> Bailian ASR/LLM/TTS
```

AI和EMQX位于同一台ECS时，网关使用 `127.0.0.1:1884`，无需让AI语音流量绕行公网。公网FMO端口由现有服务器部署决定，不应直接复制示例值。

## 数据边界

- 默认不长期保存原始语音。
- 调试音频必须设置TTL、目录权限和容量上限。
- 日志不得包含API Key、Bearer Token、MQTT密码、私钥或完整语音正文。
- 知识库原文与向量索引可放NAS，AI网关通过受控内网或反向隧道访问。

## PTT门禁

1. 只读：仅确认MQTT连接、主题与语音帧，不发布。
2. 模拟：离线执行ASR、LLM和TTS，不连接PTT。
3. 真实：由服务器所有者明确授权，仅约定呼号测试，并保留紧急关闭开关。

频道繁忙、真人正在发言、ASR输入超时或回复超过时长时，AI不得强行抢占。
