# FMO AI Voice Gateway v0.2.1

v0.2.0 的公开归档边界修正版。运行功能与安全默认值不变。

- 发布清单不再打包内部项目历史总纲、测试夹具和桥接测试素材；
- 将历史兼容函数名改为通用的“已配置管理员呼号”语义；
- 公开安装包继续排除 M5 证书签发、私钥、生产配置、音频日志和作者环境；
- 首次安装的 AI、ASR、TTS、自动回复、点名、音频播放和真实 PTT 均默认关闭；
- 升级继续保留 `/etc` 配置和 `/var/lib` 状态，并支持健康检查与回退。

验证范围与 v0.2.0 相同：Ubuntu 22.04 x86_64 执行全新安装、v0.1.2 真实归档迁移、升级与回退；Python 3.10、3.11、3.12 执行单元回归。其他声明兼容平台尚未逐一完成真机验收。
