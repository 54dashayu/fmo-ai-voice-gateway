# FMO AI Voice Gateway v0.2.0

面向个人技术研究和自动回音服务的功能版本，不是 FMO 官方组件或协议标准。

新增：

- 自动回复／鹦鹉原声回放／关闭三态，关闭鹦鹉恢复开启前的自动回复状态；
- SSTV 固定素材、图片 Robot36 编码、可选公共目录、60秒准备、计划独占和正文电平设置；
- 可选 NAS 只读图库与音乐服务，以及临时受限转码；
- 本地点名计划与可选外部点名同步；
- 同源管理请求、频道租约、繁忙跳过、停止与断线等安全门；
- 版本化安装、原子升级、自动健康检查和一键回退。

安全边界：

- 首次安装的 AI、ASR、TTS、自动回复、点名、音频播放和真实 PTT 均默认关闭；
- 升级保留 `/etc` 配置、密钥和 `/var/lib` 话术、计划及开关，不主动开启任何发射能力；
- 不包含 M5 设备证书申请、签发、私钥管理或私有发证 API/UI；
- 公共 SSTV、NAS 图库、NAS 音乐和外部点名服务均为可选显式配置，留空时安全降级。

验证范围：Ubuntu 22.04 x86_64 由 CI 执行全新安装和 doctor；Python 3.10、3.11、3.12 执行单元回归。Debian 12、Ubuntu 24.04、Rocky/AlmaLinux 9 与 ARM64 为安装器声明支持范围，本版本发布前没有全部完成真实发行版/硬件验收。

升级前可保留 v0.1.2 Release 资产作为人工回退包；新安装器也会记录上一版本并提供 `rollback.sh`。
